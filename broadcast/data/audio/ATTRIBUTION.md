# Audio attribution

The crowd beds and match effects are CC0 recordings. Each file was downloaded once, on 2026-10-20, and stored under `stems/`. The deck plays those files. It does not call Freesound.

`sources.csv` is the inventory. One row per clip. It holds the local filename, the Freesound page, the preview URL that was saved, the author, the licence, the original upload's format, and the stored file's size and duration.

The stored file is the Freesound high-quality preview, a 128 kbps MP3. The original upload is a WAV and needs a logged-in download. No music bed is used.
